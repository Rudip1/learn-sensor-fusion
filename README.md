# learn-sensor-fusion

Part of [robotics-learning](https://github.com/Rudip1/robotics-learning). Under reconstruction into a full learning module.

| folder | topic |
|---|---|
| `gnss_nmea_decoding/` | Decoding raw NMEA 0183 GNSS logs; motion, precision and fix-quality analysis |
| `gnss_lidar_fusion/` | Trajectory estimation from GNSS, LiDAR ICP odometry, and their fusion |
| `nusc_point_cloud_aggregation/` | Point-cloud aggregation from GNSS-INS poses and moving-object filtering (nuScenes v1.0-mini; download the dataset separately) |
